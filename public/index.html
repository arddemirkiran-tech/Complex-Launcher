FAQ

Is Complex Launcher free?

Completely. No ads, no telemetry, no account needed. It's a hobby-built launcher distributed freely.

Why does SmartScreen warn about the installer?

The installer is unsigned — code-signing certificates cost yearly money that a free project can't justify. Click "More info" → "Run anyway". The installer only downloads the official release zip from the project's GitHub repository.

Which loaders are supported?

Vanilla, Fabric, Forge, NeoForge and OptiFine — each instance can use a different one, with managed Java runtimes.

How does the updater work?

The launcher checks GitHub on start. Updates download in-app and apply through a crash-safe restart script: it waits for the old process, backs up the jar, copies with size validation, rolls back on mismatch, then relaunches.

Does it work offline?

Yes: offline accounts, cached version manifests and cached mod metadata let you browse and launch with no connection. Downloads obviously need internet.

Where is the cat?

Click the launcher's logo. 18 hand-coded vector scenes — the cat fishes, dives, gets teleported by Endermen and occasionally explodes with Creepers. All at 240+ FPS.
