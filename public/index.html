What's new in v49

latest release 2026-10-09

Desktop shortcut: always created, always working

Up to v46 the desktop shortcut was made once and never checked again — a marker file suppressed every later attempt. If the launcher was moved or updated afterwards the shortcut kept pointing at the old location and stopped working, and if that single first attempt failed you never got one at all. v47 throws that logic away and re-aligns the shortcut on every start and after every update.

  • It always points at something that runs — the real Complex-Launcher.exe if the package has one, otherwise the bundled runtime\bin\javaw.exe -jar "…\Complex-Launcher.jar", otherwise the JVM the launcher is running on. Flat .jar file association is no longer needed.
  • It repairs itself — a missing link, a link whose target no longer exists, or one with the wrong target, arguments or working folder is rewritten in place. Delete the shortcut and it comes back on the next start.
  • It deletes the old ones — broken links, the legacy un-suffixed variant and old version-named leftovers such as Complex Launcher v45.lnk are removed, even when their target is still valid (which is exactly the case after an update). Shortcuts that are not ours are never touched.
  • After an update the shortcut follows the launcher — every start re-aligns the link with wherever the launcher now lives, so an update that ends up in a different folder re-points the shortcut instead of leaving a dead icon behind.
  • It finds the real desktop — OneDrive-redirected desktops included, with a User Shell Folders registry fallback in several encodings when PowerShell cannot run.
  • It survives a broken or missing PowerShell through a cscript/VBS fallback, now written as UTF-16LE with a BOM: cscript reads an unmarked file as ANSI, so on a path like C:\…\Yeni klasör (7)\… the fallback used to fail silently and produce no shortcut at all.
  • Verified by driving the real production class through 33 checks on Windows, run once on JDK 25 and once on the bundled Java 17 runtime against the packaged Complex-Launcher.jar: creation, running the shortcut own command line, stale/legacy link cleanup, foreign links left alone, re-creating a deleted link, re-pointing the link after the launcher moved (simulated update), no unnecessary rewrites, and the VBS fallback on a path with spaces, parentheses and non-ASCII characters.

Includes every fix from v36–v46: server instances, Fabric & Forge launch fixes, theme and design-mode glitches, recursive dependency resolution, updater hardening and the Feedback & suggestions box.

Frequently asked

Questions & answers

Still stuck? Open an issue on GitHub — that is the support channel for this project.

Is Complex Launcher free?
Yes. Complex Launcher is completely free. There are no ads, no paid tiers and no account registration on this website.
Is Complex Launcher open source?
The full source code is published as a zip in every GitHub release for transparency and reference, but no open-source licence is granted. It is distributed free of charge, as is. See the License & credits section.
Which Minecraft versions and mod loaders are supported?
Vanilla, Fabric, Forge, NeoForge and OptiFine. Each instance can use a different loader and game version, and the launcher only installs mod builds that match the instance's exact game version and loader — a mismatched jar is never installed by accident.
How do I change the version of an installed mod?
Right-click the mod in the Mods tab and choose Change Version. A picker lists every compatible build for your current loader and Minecraft version, newest first, with the installed one marked and pre-selected. The chosen build is SHA-1 verified, its dependencies are resolved and the old jar is deleted, so two versions of the same mod never coexist. Choosing the version you already have does nothing.
Why does Windows SmartScreen warn about the installer?
The installer is not code-signed, because code-signing certificates are a yearly paid service that a free project cannot justify. Click More info then Run anyway. The installer only downloads the official release from this project's GitHub repository.
Does it work offline?
Yes. Offline accounts, cached version manifests and cached mod metadata let you browse and launch without a connection. Downloading mods, shaders, modpacks and game files obviously requires internet.
Does the launcher send any telemetry?
No. There is no analytics, no telemetry and no account system of our own. The launcher only talks to the services it needs to, listed in the Privacy Policy, plus this website when you send a suggestion yourself.
Where are my instances, mods and settings stored?
In your own user profile: %APPDATA%\ComplexLauncher on Windows, Library/Application Support/ComplexLauncher on macOS and ~/.complexlauncher on Linux. In portable mode everything stays inside the data folder next to the launcher.
Do I need to install Java myself?
No. The portable builds ship with a managed runtime, and the launcher can download and manage the Java version each Minecraft version needs.
Is there a Linux build?
Yes — a portable Linux zip with the bundled runtime is published with every release, next to the Windows installer, the Windows portable zip and the source zip.
Can I import a modpack I downloaded elsewhere?
Yes. The Modpacks tab browses CurseForge packs with one-click install and imports local .zip and .mrpack files. Any instance can be exported back to a zip to share your setup.
How much RAM should I give Minecraft?
The launcher shows a recommended value based on your system RAM. As a rule of thumb, on a 16 GB machine 6–8 GB is a good fit for heavily modded packs; leave the rest for Windows.
Where can I report a bug or suggest a feature?
Use the Suggestions box on this page, or Settings → Feedback & suggestions in the launcher (v46 and newer). Both post to the same public list, so you can see what everyone else has already asked for, and they work in Turkish or English. Longer reports with logs or screenshots are still best as a GitHub issue.
Where is the cat?
Click the launcher logo. There are 18 hand-coded animation scenes — the cat fishes, dives, backflips, chases Creepers, gets teleported by Endermen, fights Blazes, melts Snow Golems and more, all drawn as vectors at 60+ FPS.

Cookie Policy Last updated: 2026-10-08

This website uses no cookies. Not for analytics, not for advertising, not for preferences. That is why you do not see a cookie-consent banner: there is nothing to consent to.

What is used instead

  • Browser session storage (sessionStorage, one key) may cache the latest release information from the public GitHub API so the page does not repeat the request on every scroll or reload. It is not a cookie, it is not sent anywhere, it cannot identify you, and it disappears when you close the tab.
